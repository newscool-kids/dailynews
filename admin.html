회원 번호 관리

구매자에게 줄 회원 번호를 만들고, 누구에게 보냈는지 기록합니다. 이 화면의 기록은 지금 쓰는 브라우저에만 저장되니 백업을 꼭 해 두세요.

번호를 새로 만들었거나 사용 중지한 뒤 아직 '번호 목록 파일'을 저장하지 않았어요. 저장해서 앱의 data 폴더에 올려야 앱에 반영돼요.

개
  1. 번호 만들기로 번호를 미리 넉넉히 만듭니다.
  2. 번호 목록 파일 저장을 눌러 받은 codes.json을 깃허브 저장소의 data 폴더에 덮어 올립니다. 미발급 번호도 미리 포함되니, 번호를 만들 때만 한 번 올리면 됩니다.
  3. 구매가 들어오면 다음 미발급 번호 발급하기를 누르고, 복사된 번호를 구매자에게 보낸 뒤 메모 칸에 구매자를 적습니다.
  4. 번호가 공유된 것 같으면 사용 중지 후 번호 목록 파일을 다시 저장해 올립니다.
